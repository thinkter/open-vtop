# Open-VTOP

An open-source VTOP client with automatic session management.
```bash
npx open-vtop
bunx open-vtop

npx open-vtop logs
bunx open-vtop logs
```

## Getting Started

### Installation

```bash
bun i
```

### Development

```bash
bun start 
bun run logs    #for logs
```

Then open http://localhost:6767

### Production

```bash
bun run build
bun start
```
